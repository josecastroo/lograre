# lograre

**lograre** es una aplicación móvil para Android, desarrollada en Kotlin con Jetpack Compose, que ayuda a controlar el tiempo diario de uso de tus aplicaciones seleccionadas. Permite establecer un límite personalizado por cada app y las bloquea mediante un PIN una vez que se agota el tiempo asignado.

Distribuida exclusivamente como APK instalable.
